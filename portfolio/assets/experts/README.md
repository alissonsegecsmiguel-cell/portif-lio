# Fotos dos perfis

Fotos públicas de perfil obtidas das metatags og:image das páginas do Instagram indicadas por Alisson, em 13/10/2026. Sete arquivos originais têm 100 × 100 px, suficientes para retratos de 40 a 48 px na faixa. A foto de André foi corrigida usando a imagem pública de 800 × 800 px do canal de YouTube enviado, correspondente ao anexo do usuário. A Receita Previsível usa o logotipo exibido no perfil.

As imagens são servidas localmente, sem hotlink para URLs temporárias do Instagram. Para atualizar uma foto, substitua o JPG correspondente mantendo o nome. Caso altere um perfil, atualize seu link e texto nas duas cópias do grupo em index.html.
