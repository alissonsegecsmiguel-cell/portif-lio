# Logos das ferramentas

- Typebot: marca vetorial do [componente oficial TypebotLogo](https://github.com/baptisteArno/typebot.io/blob/main/apps/builder/src/components/TypebotLogo.tsx). Os dois paths foram preservados, com a apresentação branca do [favicon oficial](https://github.com/baptisteArno/typebot.io/blob/main/apps/builder/public/favicon.svg), sem a caixa de fundo do favicon.
- ClickUp: [Logomark-gradient.svg](https://clickup.com/assets/brand/v4/Logomark-gradient.svg), disponibilizado no [kit oficial de marca](https://clickup.com/brand?previewMode=true).

Os SVGs ficam locais. A apresentação inicial usa a silhueta como máscara em var(--ink), com opacidade de 70%. No hover com ponteiro fino e movimento habilitado, o SVG original aparece em 400 ms. A marca atual do Typebot é monocromática; no hover, sua apresentação branca fica integralmente visível. O ClickUp exibe o gradiente original.
